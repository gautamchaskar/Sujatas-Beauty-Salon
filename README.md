## 🚀 How to Host on GitHub Pages (Free Hosting)

Follow these simple steps to publish the website online for free:

### Step 1: Create a GitHub Repository
1. Go to [GitHub.com](https://github.com) and log in.
2. Click the **"+"** icon in the top right -> **New repository**.
3. Name your repository: `sujatas-salon` or `Sujatas-Saloon`.
4. Make sure it is set to **Public**.
5. Click **Create repository**.

### Step 2: Upload Project Files to GitHub
Run the following commands in your terminal inside this project folder:

```bash
git init
git add .
git commit -m "Initial commit for Sujata's Beauty Salon Website"
git branch -M main
git remote add origin https://github.com/<YOUR_GITHUB_USERNAME>/sujatas-salon.git
git push -u origin main
```
*(Replace `<YOUR_GITHUB_USERNAME>` with your actual GitHub username)*

### Step 3: Turn On GitHub Pages
1. Go to your repository settings on GitHub (`Settings` tab).
2. Click **Pages** on the left menu (under "Code and automation").
3. Under **Build and deployment** -> **Branch**:
   - Select **`main`** branch.
   - Select **`/ (root)`** folder.
4. Click **Save**.

🎉 Within 1 to 2 minutes, GitHub will publish your live website link at:
👉 **`https://<YOUR_GITHUB_USERNAME>.github.io/sujatas-salon/`**

## 🎴 Adding Website & QR Code to Business Card & WhatsApp

### 1. Adding to WhatsApp Business Profile
- Open WhatsApp Business -> **Settings** -> **Business Tools** -> **Business Profile**.
- Under **Website**, paste your GitHub Pages link: `https://<YOUR_GITHUB_USERNAME>.github.io/sujatas-salon/`.

### 2. Business Card QR Code Printing
- Open your live website on desktop or mobile.
- Click the **"Card QR"** button in the header or footer.
- Click **"Download QR Image"** to save the QR code (`Sujata-Salon-Website-QR.png`).
- Share this PNG image with your business card printer! When anyone scans the QR code on your card with their mobile camera or scanner app, your salon website will immediately open!
